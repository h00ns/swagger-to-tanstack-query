`swagger-to-tanstack-query`를 dev dependency로 설치한 다음, 애플리케이션에
peer dependency가 갖춰져 있는지 확인하세요.

## 생성기 설치

```bash
npm install -D swagger-to-tanstack-query
```

## Peer dependency

생성된 코드는 TanStack Query와 axios를 import하므로, 애플리케이션에 함께 설치해야 합니다.

```bash
npm install @tanstack/react-query axios
```

| Peer dependency         | 버전     |
| ----------------------- | -------- |
| `@tanstack/react-query` | `>= 5.0` |
| `axios`                 | `>= 1.0` |

## 요구 사항

**Node.js ≥ 18**이 필요합니다.
